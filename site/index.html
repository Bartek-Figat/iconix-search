Layouts

Six ways to show results

The same results, rendered six ways. Pick one per page or let people switch. Each layout uses the fields you map: title, subtitle, description, image or icon, badge, tags and meta. Need something else? renderItem takes over the markup.

CLI

Search JSON from your terminal

The package installs an iconix-search command for .json and .ndjson files. Test your ranking, check data in CI or grep a product feed with typos allowed. Add --json for machine-readable output.
